# Financial Performance & ESG Analysis

## Project Overview
An end-to-end data analytics project analyzing financial performance and Environmental, Social, and Governance (ESG) metrics across 1,000 companies from 2015 to 2025.

The project explores revenue trends, profitability, market capitalization, company growth, and sustainability performance using SQL and Power BI.

## Tools & Technologies
- PostgreSQL — Data validation, cleaning checks, and exploratory data analysis
- SQL — Aggregations, CTEs, window functions, and trend analysis
- Power BI — Interactive dashboard and data visualization
- DAX — KPI calculations and measures
- Excel — Dataset inspection

## Dataset
- Companies: 1,000
- Records: 11,000
- Time Period: 2015–2025

## Key Performance Indicators
- Total Revenue: 51.38M
- Average Profit Margin: 10.90%
- Total Market Capitalization (2025): 19.34M
- Average Growth Rate: 4.83%

## Key Analyses
1. Year-wise Revenue and ESG Score Trends
2. Industry-wise Revenue Performance
3. Regional Market Capitalization (2025)
4. ESG Score vs. Profit Margin
5. Industry and Company Performance Analysis
6. Carbon Emissions and ESG Performance

## Key Insights
- Technology leads the industries in total revenue.
- Total market capitalization in 2025 is approximately 19.34M.
- Revenue and average ESG scores show an upward trend over the period.
- ESG score and profit margin have a weak positive correlation in this dataset.
- Carbon emissions vary significantly across companies.
